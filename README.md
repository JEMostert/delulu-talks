# Delulu Talks

Local push-to-talk dictation for Linux. Install the rpm on Fedora or the pacman package on Arch from a release.

Text cleanup is on by default. After each dictation, a small model that runs on your own computer removes filler words and adds punctuation, in Dutch and English. It also names the topic of what you said, such as programming or finance, and uses it to fix words that were clearly misheard (“merch conflict” becomes “merge conflict”); History shows that topic. With Smart context management (Settings → Dictation, on by default), the next dictation hands Whisper that topic’s vocabulary and your last sentence, so names come out right from the start; the context is forgotten after 10 quiet minutes, on restart, or with Clear topic in the tray menu. The model is a one-time 5.2 GB download that runs in the background after first start. To turn cleanup off, use the Clean up text switch on the Cleanup page. That page also keeps your vocabularies: shelves of names and terms you often say, such as “T3 Code” on a Programming shelf, so cleanup can fix them when speech recognition mishears them.

Development requires Rust, Bun, GTK/WebKitGTK development libraries, ALSA, Vulkan headers, glslc, SPIRV-Headers and clang. Run `bun install && bun run build:helper`, then `DELULU_CLEANUP_HELPER=$PWD/target/release/delulu-cleanup bun run dev`; `tauri dev` does not build the cleanup helper and only looks next to the debug binary. On Fedora, if clang cannot find its headers, set `BINDGEN_EXTRA_CLANG_ARGS` to the GCC include directory. The v1 skeleton currently uses stub implementations.
