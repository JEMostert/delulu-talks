# External selected-text rewriting

The app now provides explicit, session-only external selection capture followed by an original → optional Qwen3.5 rewrite preview and a separate replacement action. Enable Ctrl+Shift+R in Selected-text rewrite, select text in a supported editor, then press the shortcut. A new capture uses a marker and an actual copy command; previous clipboard text is never treated as evidence of a selection. Capture is not persisted as a transcript or context.

The native adapter is deliberately bounded to Linux X11 with xdotool and recognized text-editor processes. VS Code/Codium, Kate/KWrite, Gedit/Xed, Mousepad/Leafpad, Geany/Pluma and Sublime are allowed; terminals and unknown applications are refused. Wayland, macOS and Windows require manually supplied source text inside the desktop technical buffer and explicit copy of the reviewed result. No editor extension or automatic replacement fallback is provided. Native selection, destination, keyboard injection and clipboard behavior have **not** been executed or verified.

Capture identifies the focused X11 window and process, copies its selection and rechecks focus. Replacement explicitly activates that same window, verifies its process/window, recaptures the current selection and rejects changed text. It checks focus again immediately before sending Ctrl+V. No Enter or generated command execution occurs. Keyboard delivery is reported as attempted, requiring destination inspection. It does not claim to identify document edits which leave an identical selection, or prevent focus changes after the final native check.

The operation holds the clipboard delivery lease. Capture and replacement preserve bounded plain-text clipboard data, restoring only while all advertised clipboard formats and bytes still match the operation's write. Rich or oversized clipboard data causes capture to refuse **before modifying it**, preserving every original format. Changed clipboard ownership is left intact. Electron provides no portable change counter; an intervening identical-byte replacement cannot be distinguished. Disabling the shortcut, renderer reload and application quit invalidate selection ownership and unregister only this shortcut.

Native selected-text acceptance remains pending regardless of roadmap issue disposition. It must exercise focus changes, editor selection changes, cancellation during asynchronous copy, clipboard changes/rich formats, missing xdotool, denied registration, delivery failure and supported desktop/editor combinations. The final consolidated pass completed mocked Python adapter checks and isolated Electron desktop, settings-write, deletion and local-data fixtures. Those passing checks do not establish external selection capture, safe native replacement, real model rewriting or destination receipt. No native selected-text validation was performed.
