# Ocean-blue interface concepts

Generated with the built-in image-generation tool. These are visual explorations, not feature specifications. The implemented direction uses concept 1's compact navy console and a light variant informed by concept 2. Unsupported controls and duplicated settings in generated mockups are excluded.

## 1. Tidal Console

Use case: ui-mockup. Create one high-fidelity desktop application screenshot, landscape 1536x1024, for Delulu Talks, a LOCAL DICTATION UTILITY. This is a working settings-first desktop tool, not a promotional website. Opening screen must immediately expose microphone dropdown, language dropdown, keyboard shortcut, hold/toggle mode, speech model, writing style, auto paste switch, copy switch, save history switch, and a prominent compact Record button. Secondary area shows latest transcript with clean/verbatim tabs and copy/edit/export actions. Other navigation: History, Writing, Wordbook, Audio files, Models, Settings. Use meaningful readable labels, dense but comfortable spacing, strong text contrast and aligned controls. No slogan, hero, illustrations, giant waveform, fake analytics, imaginary graphs, stats or promotional copy. Include a new simple original abstract wave / letter D logo, no microphone shield or orbit. Concept 1 — TIDAL CONSOLE. Dark deep navy instrument-panel interface. Narrow left navigation rail with labels; settings/control console takes the main 2/3, latest output inspector on right. Ocean blue and icy cyan functional highlights, ink-blue layered panels, square 8px corners, precision thin dividers, compact uppercase technical section labels, excellent readable white typography with monospace values. One slim luminous blue top rule and subtle vertical blue active indicators give strong identity. Distinctive professional audio-workstation character, calm and highly usable, not sci-fi decoration. Top title 'Controls', small sublabel 'Dictation configuration'. All important controls and latest output visible without scroll.
