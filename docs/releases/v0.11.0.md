# Delulu Talks v0.11.0 — Deep Sea

A visual overhaul and a reliability release. Your settings, history, corrections, text shortcuts, profiles, runtime environments and downloaded models are preserved; updating from v0.10.x does not require Repair or another model download.

## A new look: Deep Sea

- **One design system.** The renderer's styling was rebuilt on shared tokens and primitives ([design system](../DESIGN-SYSTEM.md)) with bundled Inter and JetBrains Mono, verified text contrast in both themes, and no text below 11 px.
- **Two themes.** _Abyss_ keeps the deep-sea look; the new _Shallows_ light theme turns the ocean into sunlit, caustic-lit water instead of putting pale panels on a dark sea.
- **A calmer home.** The pearl button now has a recording clock, a silence-stop countdown and a breathing state while transcribing; the latest transcript floats below with copy and open-in-history; a chip shows whether speech is ready.
- **Clearer navigation.** Sheets have titles, subtitles and a live status chip; the dock labels every destination and now includes Personalization; the command palette is a real palette.
- **Every screen revisited.** Transcript cards show one meta line with Rewritten/Corrected badges and keep technical details in a Details section. Settings is reorganized into Recording, Delivery, Rewriting, Profiles, Performance, App and Local data with plain-language descriptions. Model cards show a status badge, runtime facts and Load/Unload/Repair. Audio files, Personalization and notices share the same components.
- **New icon and tray.** The voice ribbon is recolored from mint to foam, current and ocean blue. The tray icon now shows idle, recording, busy, attention and update states on Linux, Windows and macOS, and the recording overlay uses the same palette.

## Tray and lifecycle

- The tray menu starts with a status line (sublabels never showed on Linux and Windows), adds Pause/Resume/Cancel while recording, merges paste-latest and cancel into one item, and groups preferences and destinations.
- A refused tray action (for example "Restart to update" during a recording) is shown as a notification instead of marking the speech engine failed and blocking dictation.
- macOS: clicking the menu-bar icon no longer opens the window and steals focus from the app you dictate into.
- Launch at login now works on Linux (XDG autostart) and starts quietly in the tray; on GNOME without a tray extension the window is never hidden.
- Production builds drop the reload and developer-tools shortcuts that could abort a recording; quitting waits briefly for model workers so GPU memory is released; a crashed renderer recovers automatically; the app checks for updates every six hours.

## Dictation reliability

- Audio that the recorder finishes on its own (recording limit, lost input, an unacknowledged pause) is now transcribed instead of being dropped with the app stuck in "paused" or "stopping".
- Captures fail cleanly when the recorder never starts or finishes, so dictation cannot stay "recording" forever.
- Pressing the shortcut during a paste no longer shows a JavaScript error dialog.
- Silence becomes "No speech detected" without replacing audio kept for retry; quick taps report "too short" instead of a microphone error.
- Capture resampling uses a proper anti-aliasing filter, Windows long recordings are split at quiet points instead of mid-word, and the worker's protocol can no longer be corrupted by output from vLLM subprocesses.
- Wayland paste recovers after the remote-desktop session closes; stuck paste helpers time out.

## Data and personalization fixes

- Paste recovery ("Copy instead", "Dismiss"), cancelling a scheduled paste and the setup log work again.
- Saving or activating a profile no longer fails once you have vocabulary rules; aliases survive profile switches and rule export/import.
- Exports, the tray and template exports always use the current (corrected) text, and every export uses the same guarded, atomic writer with overwrite confirmation.
- Settings number fields and the cue-volume slider can be typed and dragged normally.
- Technical dictation keeps the space in `x = (a + b)`.

## Updating

Linux AppImage and Windows installer users can download the update from Settings → App, then restart when the app is idle. Other Linux packages and portable archives require replacing the matching installation. Unsigned Apple Silicon builds use manual updates: quit Delulu Talks, replace the app using the new DMG, then reopen it.

The release workflow gates publication on cross-platform unit checks, Python checks, browser capture tests, native package builds, packaged-resource verification and release checksums. These checks do not establish physical microphone recognition, GPU inference or cross-application paste on every platform.
