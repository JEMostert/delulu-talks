# Delulu Talks v0.4.0

- **New names:** Voice is now **Siren**, Talk is **Sonar** and its helper is **Pilot**. History is **Logbook**, Audio files **Bottles**, Models **Engines** and Personalization **Lingo**. Settings, saved data and agent setups (`delulu-voice` MCP server, CLI) are unchanged.
- **Calmer interface:** page subtitles, the command palette and most helper text are gone. Home shows the engine chip only when something needs attention.
- **Siren page:** about a third of its old height. Siren and Sonar each get one card; agent setup and tuning live in collapsed sections.
- **Engines, Lingo and Settings:** shorter model cards, technical detail behind "Details", fewer descriptions and info icons.
- **Linux launcher fix:** a hidden launcher left by a development build or AppImage no longer hides the installed package's menu entry; the app removes it on start.
