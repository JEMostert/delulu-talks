# Delulu Talks v1.8.0

From v1.8.0 onward, open **Settings → About → Check for updates** to look for a newer stable release. Select **Install update**, approve the system prompt if requested, then quit Delulu Talks from the tray and reopen it. Restart any separately managed dictation daemon too.

Delulu Talks now packages the Rust desktop app for Apple Silicon Macs running macOS 15 or later. Open the arm64 DMG and drag Delulu Talks to Applications. The build is ad-hoc signed and has no Apple notarization. Gatekeeper can block the downloaded app. [Apple’s guide to opening downloaded apps](https://support.apple.com/en-us/102445)

Choose a microphone and download a speech model during setup. Allow Microphone to record and Accessibility to paste. Hold **Control+Shift+Space** in another app and release to insert your words. Dictate keeps the transcript in history and lets you change the shortcut. With Accessibility turned off, you can paste the transcript yourself with Command+V.

The Mac package includes the Metal inference engine, a click-through recording pill and the voice CLI. Models download separately. Linux packages remain available for Debian, Fedora and Arch.
