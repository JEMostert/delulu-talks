# Delulu Talks v0.12.5 — Quiet idle windows and a CPU preview

The ocean animation and voice glow now pause when dictation is idle or paused, a workspace covers the ocean, or the desktop window is hidden or minimized. Visible recording resumes decoration. Background microphone capture remains available. Workspace scrolling is smoother and respects reduced-motion preferences.

Parakeet Redux is included as an experimental, buffered CPU engine for Linux x64. It stays hidden unless launched with `DELULU_REDUX_CPU=1` and requires a manually prepared, pinned 178 MB checkpoint. Setup installs runtime dependencies only; app-managed model download and broader native validation remain pending. Preview dependencies are isolated from the normal speech runtime. The preview cannot switch to GPU engines without restarting. Normal launches continue to use R2T2 or Nemotron. See [preview setup](../PARAKEET_REDUX_CPU.md).

This release also retains v0.12.3 and v0.12.4's asynchronous KDE clipboard delivery and hold-to-talk fixes, which were present in the published tags but missing from main. Hold-to-talk delivers only after shortcut release; live typing remains available in toggle mode.

No new native inference or physical microphone validation is claimed for this release. The release workflow verifies the merged code and builds Linux, Apple Silicon and Windows packages before publication.

Local release preparation: TypeScript checks, production build, Python compilation and formatting passed. Chrome browser preview checks covered idle, recording, pause/resume and workspace coverage, and confirmed Redux is absent from normal Settings and Models choices. These preview checks do not establish native inference or actual microphone/paste behavior. Existing regression tests from both PRs and v0.12.4 were preserved during the merge.
