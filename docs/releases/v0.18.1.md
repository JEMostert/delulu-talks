# Delulu Talks v0.18.1 — Voice page in clear steps

The Voice page is now a numbered setup you follow from top to bottom, instead of one long list of settings.

1. **Turn on speech:** switch on Speak out loud, then pick and set up a voice model.
2. **Choose how it sounds:** speaker, speed, volume, output device and the Try it box.
3. **Connect your coding agents** (optional): turn it on, add Delulu to Claude Code, Codex or another MCP client, then copy the lead agent instructions. The setup commands and instructions appear once agent voice is on.
4. **Talk back to your agents** (optional): the microphone and listening settings.

A step that is done shows a check. The remaining switches (stop speaking when you dictate, read code as words, keep the model loaded) are under More options, and status messages now point to the step that needs attention. No settings, models or connections change.

Verification: formatting, TypeScript checks and unit tests passed locally, and the page was checked in the browser preview with demo data. Native macOS voice output and agent connection are still not tested on real hardware.
