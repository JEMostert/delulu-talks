# Delulu Talks v0.12.1 — Smoother dictation

This maintenance release fixes the desktop streaming contract, bounds live-audio memory and keeps the interface responsive when recordings finish. Settings, profiles, transcript originals and installed model weights are preserved.

## Dictation and live typing

- **Streaming reaches the worker.** The desktop validator still rejected the streaming commands introduced in v0.12.0. It now accepts and validates the current session commands and Nemotron responses.
- **Less retained audio.** Both speech streamers reuse their audio storage and release processed samples. A slow recognizer has bounded queues and falls back to the complete recording instead of accumulating more live audio.
- **Safer delivery.** Spacing remains correct while a paste is in flight. After any attempted live paste, a failed stream copies the full transcript instead of automatically pasting it again.
- **Clean session boundaries.** Cancellation and very short recordings close the old stream before another recording can start. A decoder that fails to finish is stopped before the buffered fallback reloads its worker.
- **Responsive Stop.** Audio merging, resampling and WAV encoding run in a local background worker. The microphone is released first; cancellation also stops encoding. The existing encoder remains available if worker startup fails.

## Interface and recovery

- Recording-clock ticks update their labels without rendering the whole workspace. History search defers expensive filtering, reuses row previews and keeps list excerpts short without truncating saved transcripts.
- The ocean background uses CSS gradients. Its software animation scheduler wakes less often, holds covered details still and sleeps while the app is hidden or reduced motion is requested.
- Import jobs keep their running identity if queue metadata cannot be saved, so completion can still be recorded.
- KDE clipboard publication has a timeout, cancelled installers still terminate surviving subprocesses, and very large local-data directories stay within the scan budget.

## Validation and updating

Local verification includes 70 TypeScript unit tests, 19 Python unit tests, both Chromium capture tests, formatting, typechecking and a production build. Browser checks covered History search/filtering, retained edit drafts across navigation and compact layout. The release workflow also checks native units, builds all three platform packages and verifies packaged resources and updater checksums before publication.

No model/GPU inference or cross-application paste was newly validated in this pass; an installed app with an active speech worker was left running. Native macOS and Windows inference still need hardware validation. No new runtime installation is required specifically for this patch; installations coming from before v0.12.0 still follow that release's **Update setup** instruction.
