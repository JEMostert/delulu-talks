# Delulu Talks v0.9.6

This release brings the ocean workspace, a compact recording controller, and the consolidated desktop dictation features from the development branch.

- Visible recording, loading, rewriting and clipboard feedback.
- Error and recovery notices stay inside panels without covering navigation.
- Improved small-window layouts and visible history filter/reset controls.
- Model shortcuts respect open confirmation dialogs.
- Personal profiles, scoped corrections, transcript review, audio imports and the technical editor remain connected to the local desktop workflow.
- Release publication now waits for all native packages and verified updater checksums.
- Mac and Windows unit checks run before merge; setup recovery fixtures handle canonical temporary paths on macOS.

## Updating

Finish recording and processing before installing. Windows installer and Linux AppImage users can check for updates in **Settings → Application**, download, then restart to install. Linux package/archive users should replace their installation using the matching download below.

On Apple Silicon, quit Delulu Talks, download the new DMG, replace the app in Applications, then reopen it. The Mac build is unsigned and uses manual updates. Keep the existing application-data directory to preserve settings, history and cached models; no data reset is needed.

Speech now uses R2T2 through MLX on Apple Silicon, vLLM on Linux NVIDIA CUDA, and native PyTorch on Windows NVIDIA CUDA. Older shared or Qwen speech setups may show **Update setup** in Models and require runtime/model downloads. Old transcript attribution is preserved. Optional Qwen rewriting is separate and opt-in.

## Verification

The local build, TypeScript, formatting, 99 unit tests, 30 Python tests, two synthetic microphone browser tests and isolated Electron smoke check pass. Browser review covered both themes, minimum/default/large window sizes, transcript corrections, editor undo and navigation, correction previews, profile activation and error recovery.

Native model inference, physical microphone input and paste into other applications were not validated on all platforms in this pass. In particular, the new Mac R2T2 route is not covered by the older Qwen Mac validation record.
