# Delulu Talks v1.1.2

Quiet recordings now reach speech recognition instead of being discarded.

- **Quiet dictation:** lowered the pre-transcription silence cutoff so soft speech and low-gain microphones can be recognized. Digital silence is still skipped; Whisper's existing no-speech filter remains active.
- **Model evaluation:** compared Parakeet TDT 0.6B v3 Q8 on CPU and Vulkan with Whisper, and checked the latest multilingual NVIDIA releases on Hugging Face. Whisper remains the app's speech engine; the benchmark evidence is included in the repository.

**Install:** the `.rpm` (Fedora), `.pkg.tar.zst` (Arch/CachyOS) or `.deb` below. It needs a Vulkan driver and, for the pill, XWayland.
