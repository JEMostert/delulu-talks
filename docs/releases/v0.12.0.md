# Delulu Talks v0.12.0 — Live typing

Your words now appear at the cursor while you speak, the speech runtime no longer claims most of your graphics card, and History, Settings, the tray and the recording overlay were redesigned. Settings, corrections, text shortcuts and profiles are preserved.

> **Linux: choose Update setup once.** v0.12.0 removes the vLLM speech server. Open Models after updating and choose **Update setup**; the R2T2 weights you already downloaded are reused.

## Live typing

- **Type while you talk.** With automatic paste on, text is typed into the app you are using as you speak, instead of after you release the shortcut. On by default; switch it off in Settings → Speech or from the tray.
- **Two speeds.** Nemotron types word by word with about half a second of delay; R2T2 types each phrase as soon as you pause.
- **Safe by design.** The complete recording is still kept, so History always has the full transcript. If live typing fails midway, nothing else is typed and the full text is copied to the clipboard instead. Live typing waits for the finished text while rewriting or spoken punctuation commands are on, because both need the whole sentence.

## Lighter speech, your choice of engine

- **No more vLLM.** On Linux, R2T2 used a vLLM server that reserved about 16 GB of GPU memory. It now runs through PyTorch/Transformers, like on Windows, and needs about 4 GB.
- **New: Nemotron 3.5 Streaming.** NVIDIA's 0.6B streaming recognizer is a light alternative: about 1.3 GB of GPU memory, or none at all with **CPU only**. If another app has filled the GPU, it moves to the CPU automatically. It is less accurate than R2T2 in Dutch, so R2T2 stays the default. Switch in Settings → Speech, on the Models page or from the tray (Linux and Windows; ~2.6 GB download).

## A calmer interface

- **Recording pill.** The large "Listening — release to send" box is now a tiny pill: a pearl that swells with your voice and nine wave bars. Text only appears for "Typed", "Paused" or an error.
- **History.** A searchable list sits beside the selected transcript, with All / Dictation / Files / Rewritten filters, day groups and multi-select export or delete. Secondary actions moved into a single **More** menu.
- **History stays small.** Only the latest 50 transcripts are kept by default (25, 100, 250 or 500 in Settings → Privacy). Older ones are removed when you update; export first if you want to keep them.
- **Settings.** Seven sections — General, Speech, Output, Rewriting, Profiles, Privacy and Advanced — each with a title, one line of context and quiet titled lists instead of stacked cards.
- **Tray.** New **Speech** menu (engine, CPU only, live typing, model state), a single **Rewriting** menu (Off or a style), and **Recent** to copy any of your last five transcripts.
- **Packaged Wayland builds** now show the ocean background and logo (pre-rendered water replaces WebGL where the GPU is disabled).

## Updating

Linux AppImage and Windows installer users can download the update from Settings → Advanced, then restart when the app is idle. Other Linux packages and portable archives require replacing the matching installation. Unsigned Apple Silicon builds use manual updates.

After updating, Linux and Windows users choose **Update setup** in Models once. Mac speech is unchanged (MLX) and does not offer live typing or Nemotron yet.

Nemotron streaming, CPU fallback and live typing were measured on Linux with an NVIDIA GPU. R2T2 through Transformers on Linux, and all native Windows inference, still need validation on more hardware. The release workflow checks unit tests, Python checks, browser capture tests, native package builds and checksums; it does not establish microphone recognition, GPU inference or cross-application paste on every platform.
