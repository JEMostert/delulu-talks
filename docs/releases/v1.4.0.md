# Delulu Talks v1.4.0

LLM FM: an optional radio station of brand-new songs, made on this computer.

- Turn it on in **Settings → LLM FM**; a new **LLM FM** page appears. Nothing is
  made or played until you press Play.
- The cleanup model writes each song's title, style and lyrics; YuE2 composes it
  in your own ComfyUI through the Comfy CLI; a host speaks between songs with
  Chatterbox Turbo's bundled voice (optional: without it, music only).
- On air with lyrics or the host's words, play/pause, skip, volume, up next,
  recently played, song requests and Direction presets (Drift, Groove, Explore)
  with mood, styles, energy, vocals, length, language, theme and host frequency.
- Missing pieces show as steps with the exact Comfy CLI command; Delulu never
  downloads music models and never starts, stops or unloads ComfyUI.
- Dictation comes first: playback is silent while you record, and no new radio
  work starts while you dictate. Native playback keeps going with the window closed.
- Restart-safe: a song already in ComfyUI is collected after a restart, never
  submitted twice. A failed song is retried once, then the station pauses briefly.
- `delulu speak --bundled-voice` speaks one reply with the bundled speaker even when
  a voice reference is configured; LLM FM uses it for the host.

Needs ComfyUI with the native YuE2 nodes and the YuE2 INT8 checkpoint, the
`comfy` command, and the cleanup model. Dictation is unchanged when LLM FM is off.
