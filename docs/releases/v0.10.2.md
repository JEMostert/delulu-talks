# Delulu Talks v0.10.2

A maintenance release that preserves your existing settings, history, corrections, text shortcuts, runtime environments and downloaded models. Updating from v0.10.0 does not require Repair or another model download.

- Spoken corrections preserve unrelated indentation and repeated spaces instead of collapsing them across the transcript.
- Unchanged profiles avoid unnecessary settings writes on startup; history lookups protect saved records from accidental mutation.
- Personalization scans protected text more efficiently while retaining exact shortcut blocks.
- A verified downloaded update survives late update-check errors, while installation failures remain visible and retryable. Restart waits for recording, inference, setup, clipboard operations and settings writes to finish.
- Development uses a rebuilt, focused unit suite plus the two existing browser capture tests. Process-heavy test fixtures and the unfinished live-streaming experiment have been removed; dictation remains buffered on every platform.

## Updating

Linux AppImage and Windows installer users can check and download in Settings → Application, then restart when the app is idle. Other Linux packages and portable archives require replacing the matching installation. Unsigned Apple Silicon builds use manual updates: quit Delulu Talks, replace the app using the new DMG, then reopen it. Keep your application-data directory; settings, history and models stay there.

The release workflow gates publication on cross-platform unit checks, Python checks, existing browser tests, native package builds, packaged-resource verification and release asset/updater checksums. These checks do not establish physical microphone recognition, GPU inference or cross-application paste on every platform.
