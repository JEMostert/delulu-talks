# Delulu Talks v0.14.0 — Automatic language and vocabulary hints for R2T2

**Automatic language detection.** On Linux and Windows, R2T2 can now detect the spoken language itself, including when you switch between Dutch and English in one dictation. Choose **Automatic detection** under Language in Settings, Quick settings or Models. Vocabulary rules, spoken formatting commands and the history language label follow the detected language. Selecting a language still forces it, as before.

**Vocabulary hints.** R2T2 now receives the correct spellings from your enabled vocabulary corrections as hotwords before it transcribes, so names and terms come out right the first time instead of only being fixed afterwards. Text shortcuts are not sent, and the list is capped at 1,000 characters. Turn it off under Settings → General → Vocabulary hints. The existing corrections after transcription still apply.

Both features use the R2T2 Transformers adapter on NVIDIA GPUs. They stay off on Apple Silicon (MLX) until they are validated on a Mac. Parakeet Redux already detects the language and does not accept hotwords.

Verification: TypeScript checks, 73 unit tests, the Python suite, five browser tests and the production build passed locally. With the real R2T2 model on an RTX 4090, through the app's worker protocol:

- Vocabulary hints turned "Castelvintime", "Mondream" and "de Lulu" into "Kestrel", "Moondream" and "Delulu", and left sentences without those terms unchanged.
- Automatic detection labelled Dutch and English correctly and transcribed a mixed Dutch-English clip in full.

These were synthesized test clips on one machine, not a recognition-accuracy benchmark. Hints help but don't guarantee every spelling.
