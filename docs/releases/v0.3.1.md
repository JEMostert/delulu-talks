# Delulu Talks v0.3.1

- **Dictation cleanup:** Clean up removes hesitation sounds, attempts to apply spoken corrections, and tidies punctuation while retaining the original transcript in history.
- **Writing models:** choose Qwen 3.5 2B or Phi-4 mini. The Talk helper continues to use its separate lightweight model.
- **Simpler settings:** rewrite settings put the active style first and group other styles separately. Quick settings now correctly reflects whether rewriting is enabled.

The cleanup can still miss corrections or retain a cancelled request, especially in Dutch. Review important dictation before acting on it. Talk and rewrite have not been validated together with a live microphone in this release.
