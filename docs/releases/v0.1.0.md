# Delulu Talks v0.1.0 — rebuilt on Tauri

Delulu Talks is rebuilt on Tauri 2 with a Rust backend. It looks and works the same; underneath, Electron is gone. Release numbers restart here, and the old Electron releases are removed.

## What changes for you

- **Smaller and lighter.** The app uses your system's webview instead of bundling Chromium and Node.
- **Native audio.** The microphone, capture cues, listening mode and voice playback run in the Rust backend (PipeWire/PulseAudio or ALSA on Linux, CoreAudio, WASAPI), so dictation records reliably while another app has focus.
- **Voice MCP without Node.** Coding agents run `delulu-talks mcp`. Copy the new setup command from the Voice page and register it again in Claude Code, Codex or your MCP client; the old `node …/delulu-voice-mcp.mjs` entry keeps working only where Node is installed.
- **Packages for your distribution.** AppImage, rpm (Fedora), deb (Debian/Ubuntu) and pacman `delulu-talks-bin` (CachyOS/Arch), plus a macOS Apple Silicon DMG. Windows is no longer supported.
- **Signed updates.** The AppImage and macOS app update in the app from signed releases. rpm, deb and pacman installs update by installing the newer package.
- **Profile recovery** is now `delulu-talks restore-profile`.

## What carries over

Your profile stays where it was (`~/.config/Delulu Talks` on Linux), so settings, history, word packs and shortcuts, installed speech, writing and voice runtimes, and downloaded models are picked up without setup. Electron releases do not update to this version on their own: install a package from this release. On Arch and CachyOS, pacman offers to replace the old `delulu-talks` package with `delulu-talks-bin`; an old AppImage can simply be deleted.

## Known limitations

- Listening mode has no echo cancellation. Barge-in uses Delulu's own playback level as a reference; with speakers close to the microphone, use headphones.
- The recording pill is not available on GNOME, which has no layer-shell. It works on KDE Plasma.
- The macOS package is built but not yet verified on real hardware.
- The native inference harness and speech benchmarks are not ported yet.
