# Delulu Talks v0.16.0 — Three speech model sizes

**Pick a size.** Delulu now offers three local speech models, from small to large:

- **Small · Canary 180M** (200 MB) runs on almost any computer. English, German, French and Spanish.
- **Medium · Parakeet 0.6B** (630 MB) is fast and accurate on any CPU. English uses NVIDIA's English model, Parakeet TDT 0.6B v2; Automatic detection uses v3, which recognizes 25 European languages. Medium is the default for new installations.
- **Large · R2T2** (about 4 GB) is the most accurate, with 30 languages, automatic detection and vocabulary hints. It needs an NVIDIA GPU or Apple Silicon, as before.

Choose in Models, in Settings → Speech or from the tray menu.

**Nothing downloads before you choose.** On first launch, Models shows the three sizes. No runtime or model is installed until you press **Download & set up**.

**Small and Medium run on the CPU everywhere.** They use sherpa-onnx, on Linux, Windows and macOS. Their runtime is about 140 MB and installs no PyTorch, CUDA or GPU driver. Previously every installation needed an NVIDIA GPU or Apple Silicon. Large still installs the PyTorch/CUDA or MLX runtime, which also contains the CPU packages. Switching down from Large, or between Small and Medium, therefore needs no new setup. Switching up to Large asks for setup once.

**Parakeet Redux is removed.** It was a 1.58-bit compressed copy of Parakeet v3 that ran only on Linux x64. If you used it, you are moved to Medium. Press **Download & set up Medium** once to install the new CPU runtime. If you used R2T2, you are moved to Large and nothing changes. Moving from an older R2T2 runtime to Small or Medium asks for setup once, because older runtimes lack sherpa-onnx; that setup installs only the CPU runtime.

**Languages follow the model.** The language list shows what the selected size accepts. When you switch sizes, a language the new model cannot use falls back: to English on Small, or to Automatic detection on Medium. On Small, choose the language you speak: Canary translates speech in another language into the selected one.

Verification: the TypeScript checks, 87 unit tests, the Python suite (34 tests), the five browser tests and the production build passed locally. With a fresh profile, a real Electron run on Linux (Python 3.11):

- The first-run picker downloaded nothing until setup was pressed.
- Medium set up a 139 MB CPU runtime and transcribed the repository's English fixture correctly.
- Small (English and German) and Medium Automatic (Parakeet v3) loaded and transcribed in the same session without a restart.
- Choosing Large on the CPU runtime asked for setup.
- Setting up Large then installed the CUDA runtime with the CPU packages. R2T2 ran on an RTX 5060 Ti, and Medium and Large switched back and forth without further setup.

Windows and macOS have not been run natively. Accuracy figures in [Model research](../MODEL_RESEARCH.md) are published read-speech benchmarks, not measurements of your dictation.
