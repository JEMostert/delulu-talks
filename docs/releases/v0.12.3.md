# Delulu Talks v0.12.3 — KDE dictation delivery

Fixes a delivery failure observed in a local v0.12.2 installation: speech recognition succeeded, but KDE clipboard publication timed out (`qdbus6 ETIMEDOUT`), leaving the transcript in History instead of delivering it.

- KDE clipboard publication now runs asynchronously so Electron can continue serving Wayland clipboard requests. It retains a two-second timeout and waits for acknowledgement before sending paste keystrokes.
- Copy actions, tray actions, scheduled clipboard delivery and dictation now await publication. Concurrent clipboard operations cannot overwrite a pending delivery.
- Failed live typing no longer claims the complete transcript was copied when clipboard recovery also failed.
- Model failures display a classified, actionable cause instead of directing users to diagnostics that omit that cause. Raw backend text remains private.

## Verification

72 TypeScript unit tests, 19 Python unit tests, both Chromium microphone tests, formatting, typechecking and a production build passed locally. The new regression cases cover asynchronous KDE acknowledgement and accurate failure reporting after live fallback.

Native Linux checks used the existing cached models on an RTX 4090. R2T2 completed two worker requests. Nemotron completed buffered inference and two consecutive streaming sessions. In an isolated Wayland desktop, the built Electron app captured the synthetic speech fixture, recognized it with R2T2 and published it successfully to the real Plasma clipboard. Nemotron also completed the desktop capture-to-history path. Browser preview checks use demo data and do not establish native delivery.

The observed installed-app clipboard timeout was not reproduced by a minimal isolated clipboard probe; both synchronous and asynchronous calls succeeded there. The fix removes the blocking clipboard exchange that can prevent Electron from serving selection requests. Physical microphone quality, paste receipt in every destination application, and native macOS/Windows inference are not certified by these checks.

No runtime repair or model download is required for this patch. Existing settings, history and cached models are preserved.
