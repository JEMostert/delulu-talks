# Delulu Talks v0.17.0 — Delulu Voice

**Delulu can talk back.** Turn on **Speak out loud** on the new Voice page and Delulu reads text aloud with a local voice model. Nothing leaves your machine.

- **Small · Kokoro 82M** (about 330 MB) runs on any CPU, with 27 American and British English voices.
- **Large · Chatterbox Turbo** runs on a GPU (about 3 GB of memory). It really laughs, sighs and whispers, and can speak in a voice cloned from a 5–20 second clip.

Each model is set up once from the Voice page, in its own runtime. Nothing downloads before you press **Download & set up**.

**Grok-style tags.** Write `[laugh]`, `[sigh]`, `[pause]` and other one-off sounds inline, and wrap spans in `<whisper>…</whisper>`, `<happy>…</happy>`, `<slow>…</slow>` and similar styles. Kokoro handles pauses, pacing and volume and skips the rest; every result lists what was skipped. See [Delulu Voice](../VOICE.md) for the full list.

**Your coding agent briefs you.** Turn on **Let coding agents speak** and copy the one-line setup for Claude Code or Codex (T3 Code uses theirs). You keep dictating to one lead agent; it runs its own subagents and tells you out loud when work is done, blocked or needs a decision. Copy the agent instructions from the Voice page into your `CLAUDE.md` or `AGENTS.md`. The connection is a local, token-protected socket; a small MCP server and command-line tool come with the app.

**Answer right away.** Starting a dictation stops Delulu talking before the microphone opens. Speech starts after the first sentence is ready, while the rest is generated. File names, paths and code are read as words, and code blocks are skipped.

**Also:** "Read clipboard aloud" and "Stop speaking" in the tray and command palette, an output device choice, speed and volume, and `--read-clipboard` / `--stop-speaking` launch flags for custom shortcuts.

Verification: the TypeScript checks, unit tests, the Python suite and the production build passed locally. On Linux with an RTX 5060 Ti, the app's installer built the voice runtime, and both models spoke through it with tags performed rather than read out (checked with Parakeet). Windows and macOS voice runtimes have not been run natively.
