# Delulu Talks v0.2.0

- Add an optional, fully local voice coordinator: Qwen3.5-0.8B (Lightweight) or Qwen3.5-2B (Conversational). Off/direct remains the default. Choose a model on the Voice page and explicitly set it up; ordinary loading uses cached files only.
- Route original user wording and ordered corrections to coding agents without generating or rewriting their task prompts. Agent planning stays with the work agent.
- Add durable, harness-neutral CLI/MCP agent inboxes with acknowledgments and explicit queued, accepted, running, blocked and finished task states. Generic hosts need an inbox waiter or a compatible host adapter; queued delivery does not automatically wake an idle agent.
- Keep helper inference in a dedicated process while sharing pinned model files and the writing runtime. Helper setup and writing setup are serialized.
- Preserve completed turns across stop/unload/restart. Interrupted transcription recordings are retained separately and retried before reopening the helper microphone. Cancellation stays a request until the worker confirms stopping.

Both model sizes were exercised locally on NVIDIA CUDA. Task-reference and cancellation guards currently use conservative English cues; uncertain targets are omitted. A live microphone round-trip with the new coordinator still needs user validation.

This release retains the Linux AppImage rendering and NVIDIA Wayland fixes from v0.1.1.
