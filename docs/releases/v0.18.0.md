# Delulu Talks v0.18.0 — Voice conversations with coding agents

**Talk with your agent in turns.** A coding agent can now start a listening session once. Delulu keeps the microphone and speech model running, notices when you start talking, and finishes your turn after a short pause. The agent collects each turn with a short waiting command, answers out loud, and waits again. Turns you speak while it is busy are queued, not lost.

**Talk over it.** While Delulu is speaking, the microphone stays on. When you keep talking for about 0.3 seconds, Delulu stops at once, drops the rest of that answer, refuses any audio still being generated for it, and captures your whole sentence, including its first words. The agent is told which answer was interrupted and gets your new turn next.

**Not hearing itself.** The session's microphone uses the browser's echo cancellation, ignores sound that is no louder than Delulu's own playback leaking in, and drops transcripts that match what Delulu just said. Headphones still give the most reliable interruptions; on loud speakers you may need to talk clearly louder than the playback.

**For agents.** The bundled script gained `listen start`, `listen next`, `listen ack`, `listen status` and `listen stop`, plus `say --response ID`; the MCP server has matching tools. Every turn has a sequence number: an agent passes the last one it handled, so retries and reconnects get the same turn again instead of losing it, and one agent cannot read another's session. The Voice page installs a `delulu-voice` skill for Claude Code and Codex that teaches the listen → answer → listen loop and where each host can and cannot wake an idle agent.

**In the app.** The Voice page has a Listening section with sensitivity, pause length and interruption settings, recent turns, and Start/Stop. A "Listening · Stop" pill shows on every page while a session runs, and the tray can stop it. Dictation still works during a session: the session pauses while you dictate and resumes afterwards.

Verification: TypeScript checks, unit tests (including speech detection and barge-in on speech generated with Kokoro, with simulated echo and background noise), the Python suite and the production build passed locally. Real speaker-to-microphone echo and Chromium's echo cancellation on physical hardware were not tested; Codex waking an idle agent from a background command is unverified.
