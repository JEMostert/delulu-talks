# Delulu Talks v0.1.1

- Fix severe animation lag in the Linux AppImage on newer systems. When a newer, compatible system WebKitGTK is installed, the app now uses it instead of the bundled copy. Systems without compatible libraries keep using the bundle.
- Work around an NVIDIA Wayland explicit-sync error that could prevent the window from opening, while keeping hardware compositing enabled.

On CachyOS with NVIDIA and KDE Wayland, the animated ocean improved from roughly 3–5 fps with bundled WebKitGTK 2.50.4 to 60 fps with system WebKitGTK 2.54.1 in a private 60 Hz test desktop.

For troubleshooting, `DELULU_BUNDLED_WEBKIT=1` keeps the bundled WebKitGTK. Existing `DELULU_SOFTWARE_RENDERING=1` and explicit NVIDIA driver settings remain supported.
