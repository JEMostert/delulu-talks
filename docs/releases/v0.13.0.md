# Delulu Talks v0.13.0 — Parakeet Redux for everyone, and a leaner app

Parakeet Redux is now a normal speech engine on Linux x64. Select it in Settings → Speech, Models or the tray: there is no launch flag and no manual model preparation. The app downloads and verifies the pinned 178 MB checkpoint on first load, and later loads work offline. Redux runs on the CPU and leaves the GPU free. It detects the spoken language automatically. Switching between R2T2 and Redux works without restarting. Its Kestrel runtime installs into the normal speech environment, so existing Linux installations need **Update setup** once (about 700 MB).

Nemotron 3.5 Streaming is removed. It was less accurate than R2T2, especially in Dutch. Saved Nemotron selections fall back to R2T2.

Live typing is removed. Dictation now always delivers the whole transcript at once after you stop (with hold-to-talk, after you release the shortcut). Also removed:

- the Editor page and its unused code and command dictation modes;
- the X11-only selected-text workflow;
- export templates (plain TXT/MD/JSON export remains);
- vocabulary import, export and bulk editing;
- project vocabulary.

Old settings and history load normally; removed fields are dropped on load.

Fixes:

- A pause the recorder never acknowledges no longer leaves capture stuck.
- A failed history write after a successful paste or copy is no longer reported as a failed delivery.
- Startup shortcut registration and shortcut changes no longer race on the desktop portal.
- Settings now apply even when a busy model can't unload yet.
- The overlay helper is force-stopped if it ignores shutdown, and its preview exports no longer use a fixed `/tmp` path.
- Worker shutdown no longer waits out its fallback timer when the process has already exited.
- Parakeet Redux frees memory even when its runtime shutdown fails. It also rejects empty audio and reads formats soundfile can't decode.
- Rewrite warmup no longer stays stuck at "warming" after a failed first request.
- Qwen rewrite checkpoints are pinned to fixed revisions.
- Repeated checksum failures keep at most one corrupt copy instead of piling up multi-GB files.
- The browser preview mock no longer ships in the desktop bundle.

Verification: TypeScript checks (now also rejecting unused locals in the main process), 68 unit tests, the Python suite, five browser tests and the production build passed locally. With the app's worker protocol, Parakeet Redux downloaded and verified its checkpoint, loaded in 5.6 s (2.2 s offline), and transcribed the test fixture correctly in 0.09 s on an i9-13900K. Switching R2T2 → Redux → R2T2 in one worker freed the GPU while Redux was active. That is one English fixture on one machine, not a Dutch accuracy benchmark. Physical microphone and paste behavior in the packaged app were not exercised for this release.
