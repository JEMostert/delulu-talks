# Delulu Talks v1.4.1

LLM FM is now called **Delulu FM**, plus fixes found while checking v1.4.0 on a
real install. Your songs, history and settings carry over unchanged.

- The radio's tab, page and Settings switch are named Delulu FM, and the host
  introduces the station by that name.
- With ComfyUI simply not running, the Delulu FM page now asks only to start it.
  YuE2 nodes and the model show as "Checked once ComfyUI is running" instead of
  asking you to update ComfyUI or install a checkpoint you may already have.
- A song waiting for a stopped ComfyUI now says so in one plain line instead of
  the Comfy CLI's raw diagnostic text.
