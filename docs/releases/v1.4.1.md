# Delulu Talks v1.4.1

LLM FM fixes found while checking v1.4.0 on a real install.

- With ComfyUI simply not running, the LLM FM page now asks only to start it.
  YuE2 nodes and the model show as "Checked once ComfyUI is running" instead of
  asking you to update ComfyUI or install a checkpoint you may already have.
- A song waiting for a stopped ComfyUI now says so in one plain line instead of
  the Comfy CLI's raw diagnostic text.
