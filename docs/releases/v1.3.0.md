# Delulu Talks v1.3.0

Optional spoken replies for agent harnesses, alongside existing dictation.

- Linux packages now include the lightweight `delulu` Rust CLI. Run `delulu setup`
  to install configuration and the short global `delulu-speak` agent skill.
- `delulu speak 'Done. Ready for review.'` speaks on demand; piped text works too.
  Each invocation releases the model and GPU memory before playing its audio.
- Voice replies in Settings shows optional model installation, progress, readiness
  and retryable errors, using the existing interface design.
- Model weights are never downloaded during app installation, first launch,
  opening Settings or CLI setup. Click **Install model** or explicitly run
  `delulu install-model` to opt into the roughly 3 GB Chatterbox Turbo download.
- Setup reuses an existing compatible Python/torch runtime, including the local
  AI Director environment, without upgrading it or installing a second CUDA stack.
  Use `--python /path/to/venv/bin/python` to select another compatible environment.
- Uses the official bundled speaker unless a voice reference is explicitly chosen.
  Existing listening and input flows are preserved.
- Concurrent speech jobs queue; Ctrl-C and SIGTERM stop owned work. `--output`
  saves a WAV without playback; `--volume 0` mutes only that playback stream.

Speech output requires a compatible Python Chatterbox Turbo environment and
PipeWire's `pw-play` for playback. English speech, CUDA by default, optional CPU.
The CLI embeds its Python adapter and agent skill: no source checkout is needed.
